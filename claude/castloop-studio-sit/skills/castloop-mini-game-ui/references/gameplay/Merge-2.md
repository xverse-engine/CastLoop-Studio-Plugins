# Merge-2 投放合成

上方左右瞄准并松手投一颗，同级物件碰撞合成。关卡目标、固定序列、投料上限与故事节点通过该玩法项目配置。目标达成先于同一步的失败判定，成功回传宿主。参考实现用量耗尽最多等 4 秒；新球 1.8 秒入场豁免，连续危险 3.2 秒溢出失败，显示红线和倒计时。此处时长是已验收的参考玩法值，改规则应更新引擎及测试。

- 宿主演绎触发小游戏后，或直接打开独立预览时，首个玩家界面是主游戏背景上的「目标＋开始」弹窗。弹窗同时展示目标和唯一的开始按钮；点击后进入双面板游戏。禁止在它之前插入封面、旁白或额外开始页。成功按既有流程返回演绎。失败显示原因、缺少物件图与数量。目标弹窗与主面板共用「委託 01/10」格式，实际数量由项目定义。
- 工具进入时冻结运动和计时。换料选 Lv.1–3；救援点选实际物件并确认。救援替换上方面板内容，提示 12 px、四边完整；下方操作区坐标、宽高与普通态完全一致。命中以物件实际显示位置为准。
- 每局初始次数及费用由宿主约定。免费次数用完后打开系统付费组件。购买成功立即记入本局次数并保存，取消选择、无效操作、刷新恢复同一局都保留，成功使用才消耗。重试重置局内道具，次数不跨局。
- 故障与失败面板提供明确重试；次按钮为打开故事树，示例只用 Toast 示意。广告可用时直接播放，完成后自动重开；不可用时给 Toast 且留在失败页。钻石重试时在失败页上叠加系统蒙层与付费组件，取消返回原失败页。
- 预览侧栏支持直接替换六种检查状态，包括两种失败原因、广告可用／不可用、付费重试和无法恢复。预览入口不消耗实玩重试次数。
