# 正式版接入准备

本文件是发布准备，不表示正式服务已上线。SIT 插件与市场保持原身份。

- 正式后端启用 /mcp，资源 audience 与正式 HTTPS 地址完全一致；配置正式 Logto issuer/JWKS，沿用作品编辑权限检查。
- 正式 Logto 使用验收过的版本和刷新令牌配置；数据库迁移先备份并按独立迁移流程执行，不能直接假设 SIT 数据库状态适用于 PRD。
- 创建正式公共原生 OAuth 客户端，取得真实 client_id 后才生成正式插件配置；不复制 SIT client_id、不放 client_secret。回调匹配实际客户端的 loopback OAuth 行为。
- 正式插件使用独立 castloop-studio 名称/正式 MCP URL；SIT 保留 castloop-studio-sit。公开市场默认只列正式插件，开发市场保留 SIT。先核对公开文件不含验收故事、凭证、内部日志。
- 发布前验证登录、续期、无权限访问拒绝、最小读写、收费生成/重复请求、导入导出签名链接。多账号验收可后置开发，但正式开放前至少确认权限隔离。
- BYOK、多端同时修改冲突、自动后台恢复不在本次范围；说明中不承诺这些能力。
