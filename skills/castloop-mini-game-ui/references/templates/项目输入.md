# 新故事输入模板

1.2：不懂代码的作者可以只提供自然语言想法与故事节点，Agent 按 [自然语言创作](../common/自然语言创作.md) 生成 H5、参数与关键参数表单，不要求作者填写 JSON。未指定的权益配置使用 10 钻、1 次免费、会员可用、广告可用；作者指定值优先，包括 0/false，真实资格和广告入口由宿主决定。

- **模式与绑定**：preview、integration 或 production，稳定 gameId、gameVersion、故事发布版本、nodeId、interactionId、SDK 协议与目标渠道。生成任务的 previewOnly=true 不代表正式消费端已注册。
- **参数与复用**：描述需调整的关卡、难度、目标和时长，Agent 生成完整 miniGameData 与 editorSchema。项目内节点复用同一素材的固定版本，分别保存参数；平台生成 generatedAsset 引用，Skill 不伪造任务 ID 或自行绑定其他节点。
- **资源归档**：当前故事资产根目录，每个小游戏独立的 gameId 和版本目录 `mini-games/<gameId>/<gameVersion>/`；所有运行图片最终为 WebP，原稿不打入运行包。列明需要保留的透明、原像素、逻辑显示尺寸及动画。
- **商业声明**：稳定 offerId／grantKey、提示／道具／重试等用途、unlock 或 consumable、有效范围、期望钻石／会员／广告方式。真实报价和资格由平台下发。
- **进度与结果**：runId 管理方式、saveSchemaVersion、兼容或迁移策略、允许 resultCodes、成功／失败／退出连线。
- **宿主交付**：正式 hostBridge、所需能力、Mock 测试状态、登录／充值／会员／广告返回恢复方式。宿主尚未实现时只交付技术预览，不能宣称已上线。

- **故事**：唯一 ID、标题及各语种译名、简介、封面、情绪关键词、场景与物件、剧情插入节点及返回路径。
- **现有视觉**：指定色板、字体类别及逐语种映射、定制化 UI 素材和生图模板、禁止项。列适中／高／极高的构图与材质差异（如果需要多档）。
- **玩法**：选择已有玩法或提交新的规则。列页面、低保真链接、每个状态的触发及去向、输入、计时、胜负、工具、资源槽位、存档及失败恢复。
- **宿主**：演绎示例、系统组件链接、价格、广告条件、成功回传与故事树去向。明确哪些只是 Demo 模拟。
- **交付**：语种、基准宽度、需验证的设备与路径、输出位置。

可直接用于下一轮的任务描述：

> 使用 CastLoop 小游戏 UI Skill 1.2。故事资料为［文件或链接］，玩法描述为［自然语言描述］，已有结构稿为［链接，可省略］。按我的主题色和字体生成单一可玩版本，自动生成完整参数和可编辑关键参数定义，不要求我编写 JSON。所有运行图片统一 WebP，每个小游戏打包到［故事资产根目录］下独立的 mini-games/gameId/gameVersion 目录。输出可玩预览、主题素材及提示词、可复用项目和验证结果，供平台加入项目素材库并在不同节点分别配置。缺少影响玩法的输入时列出待确认项。

预览交付时，请实际生成并接入各档场景图、九宫格框体与玩法物件图，附上 art-manifest.json、原图和提示词。请核对所有玩家界面状态的指定字体及字重，并提交实际图片与字形加载的验收结果。
